## 📖 Descripción

Bienvenido a HitCraft, un servidor de Minecraft diseñado para ofrecer una experiencia estable, divertida y bien organizada. Aquí podrás disfrutar de un entorno optimizado con funciones personalizadas sin perder la esencia clásica del juego.
